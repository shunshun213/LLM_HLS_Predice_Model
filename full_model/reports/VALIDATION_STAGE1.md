# Stage 1 validation (HLS code + clock -> HS -> Stage 2)

Generated by `stage1_report.py`. Input = source pragmas (Tcl directives when the source has none) + clock; no tool output is read on the prediction path.

**Scope of these numbers.** The Stage-1 rules were derived by inspecting all 510 designs (train and extra). No Stage-1 number below is out-of-sample: "extra" is the development set on which most rules (core latencies, depth offsets) were characterized, and "train" was also inspected. LOGO (section 3) holds out a group only from the Stage-2 constant fit; the Stage-1 rules are in-sample for every group. Section 5 lists how many designs support each data-derived rule branch; branches with few supporting designs are low-confidence.
